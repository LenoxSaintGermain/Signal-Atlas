# Suite Distilled Command Center Spec

## Intent

Evolve `Suite Distilled` from a `Living Strategy` memo into a predictive navigation layer.

The upgraded module should feel like:

- the market awareness of a WSJ lead story
- the categorical rigor of a Gartner-style analyst brief
- the operational clarity of a strategy command center

This module should stop acting like a recap of what the suite already knows.
It should become the surface that recalibrates the user's flight path as signals, evidence, and execution outcomes change.

## Current Problem

The current `suite_distilled` module is still the old summary shell:

- two static columns
- one simple `next_to_do` strip
- no market positioning model
- no dynamic recalibration
- no branching execution logic
- no visible relationship between internal signal and external market conditions

That means the module underperforms its role.
It should be the strategic command surface between `The Brief`, `Your Plan`, `Professional DNA`, and the human advisor.

## Product Reframe

Keep the `Living Strategy` work as the foundation, then add a second layer:

- `Living Strategy` = strategy memo
- `Command Center` = predictive navigation engine

Recommended client-facing title:

- `Your Command Center`

Recommended subtitle:

- `A living execution sequence recalibrated by market signal, proof, and momentum.`

## Core Product Pillars

### 1. Macro-to-Micro Intelligence Layer

Purpose:

- combine external market posture with the user's current career signal
- translate macro noise into immediate decision value

Required capabilities:

- `market_sentiment_summary`
- `hot_skill_premiums`
- `restructuring_or_cooling_signals`
- `positioning_matrix`
- `career_lane_recommendation`

Important note:

Do not use `Gartner` or `Magic Quadrant` language directly in the shipped UI.
This should become a `Career Positioning Matrix` or `Market Positioning Matrix`.

Matrix states can be:

- `Leader`
- `Challenger`
- `Specialist`
- `At Risk`

### 2. Surgical AI Leverage

Purpose:

- move beyond generic AI advice
- provide exact AI-enabled methods that help the user advance the current search

Required capabilities:

- `proxy_interview_playbooks`
- `narrative_shaping_recipes`
- `artifact_repackaging_routes`
- `recruiter_language_transformations`
- `evidence_to_story_conversions`

This section should tell the user exactly how AI should be used against the current constraint pattern, not how AI works in general.

### 3. Living Playbook

Purpose:

- make the module behave like a GPS, not a PDF
- update sequencing when new user actions or new market signals appear

Required capabilities:

- `signal_based_recalibration`
- `branching_next_moves`
- `unlock_conditions`
- `execution_feedback_adjustments`
- `proof_gap_prioritization`

Examples:

- outreach feedback says the narrative is too technical
- update the branch priority toward executive framing and stakeholder-safe artifacts
- completed coffee chat creates a new unlock path for sponsor follow-up or proof capture

## Information Architecture

### Zone A: Market Frame

Top editorial strip.

Contents:

- current strategy status
- market sentiment snapshot
- positioning matrix state
- short `what changed` note
- evidence/freshness strip

### Zone B: Command Center

Primary decision surface.

Contents:

- current position vs target position
- positioning matrix
- lane recommendation
- most important recalibration note

### Zone C: Surgical Playbooks

Execution section.

Contents:

- proxy interview playbook
- recruiter-language playbook
- narrative-shaping playbook
- evidence-hardening playbook

### Zone D: Living Sequence

Dynamic roadmap section.

Contents:

- current branch
- alternate branch
- unlock conditions
- proof targets
- next `72 hours`
- next `2 weeks`

### Zone E: Advisor Bridge

Human handoff section.

Contents:

- what changed since last review
- what needs advisor judgment
- what can be delegated to AI
- strategic questions for the next session

## Data Integrity Rules

This module must not fake live intelligence.

Allowed:

- latest source-backed market snapshot already generated by Professional DNA
- internal user execution signal from plan, interactions, and artifacts
- explicit inference labels

Not allowed:

- decorative fake trend lines
- implied real-time labor data without a source-backed refresh
- trademarked analyst-framework mimicry in the shipped UI

Every meaningful statement must remain classed as:

- `Observed`
- `Inferred`
- `External`

## Generation Contract

This module should synthesize from:

- `brief`
- `suite_distilled` v2 living-strategy fields
- `profile`
- `ai_profile`
- `gaps`
- `plan`
- `readiness`
- Professional DNA:
  - `market_signal`
  - `market_demand_analysis`
  - `compensation_position`
  - `source_registry`
  - `evidence_nodes`
- user execution state when available:
  - outreach or interaction logs
  - completed tasks
  - advisor feedback notes

## Protocol Alignment

| Protocol | Requirement | Command Center Response |
| :--- | :--- | :--- |
| `global_interaction_density_and_guidance_spec` | first proof of state inside first viewport | top strip shows strategy status, matrix state, and what changed immediately |
| `global_interaction_density_and_guidance_spec` | one dominant narrative block | the command-center thesis is the dominant block; playbooks and sequences remain subordinate |
| `micro_interaction_cinematography_spec` | motion explains hierarchy | recalibration state changes should glide and re-emphasize affected branches only |
| `dossier wsj / microinteraction appendix` | attentive, not animated | signal shifts, branch unlocks, and evidence refreshes should feel quiet and exact |

## Acceptance Criteria

1. The first viewport shows the user's current market posture, matrix state, and biggest recalibration note.
2. The module tells the user what changed, not just what is true.
3. AI playbooks are specific enough to execute immediately.
4. The roadmap can branch based on feedback, proof, or market movement.
5. No external-market claim is rendered without a freshness note or evidence class.
6. Legacy `suite_distilled` artifacts still degrade safely.
