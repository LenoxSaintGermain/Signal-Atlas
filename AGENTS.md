## Workspace Extensions

This workspace includes a curated local mirror of the Orbital `.agent` library at:

- `.context/orbital-agent/README.md`

Use it as a reference layer when tasks clearly match those workflows or skills, especially for:

- planning and spec work
- frontend design / upgrade-from-reference passes
- architecture and hardening
- debugging and verification
- backlog / artifact logging discipline
- parallel execution patterns

Preferred workflow:

1. Check `.context/orbital-agent/README.md` or run `./orbital list`.
2. Use `./orbital show skill <name>` or `./orbital show workflow <name>`.
3. Apply the workflow manually in this repo.

Do not assume these are automatically registered runtime skills.
Treat them as workspace-local operating playbooks.
